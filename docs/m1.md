## 2. 包结构

```

  rpc.mbt                JSON-RPC 2.0 帧、错误码、解析/构造
  events.mbt             EventEnvelope（id/org_id/type/ts/subject/seq/...）
  methods.mbt            host.status / events.subscribe 常量与结果结构
  discovery.mbt          host.json（HostInfo）与路径
  ids.mbt / time.mbt     ULID 前缀 ID、RFC3339 毫秒 UTC
packages/providers       monexus/providers
  error/                 ProviderError（auth_failed/remote_exit/... 区分）
  ssh/                   SshTarget/argv/probe/run（自 M0 迁入）
  pty/                   run_pty_check（自 M0 迁入）
packages/host-client     monexus/host-client
  discovery.mbt          default_state_dir + host.json 读取
  client.mbt             Bearer WS 连接、单请求在途、status/subscribe/event

  linux_skia/            async main + Vulkan linker shim

```

## 3. Host 协议

- 端点：`ws://127.0.0.1:<随机端口>/ws`，仅 loopback。
- 握手：HTTP `Authorization: Bearer <token>`；缺失/错误返回 401，路径错误 404。
- 请求：
  - `host.status`：返回 host_id/version/status/pid/started_at/uptime_ms/
    event_seq/state_dir/protocol_version。
  - `events.subscribe`：`params.since`（可选）回放 `seq > since` 的事件；
    响应后紧接 `events.event` 通知。
- 通知：`events.event`，`params.event` 为完整事件信封。
- 事件：`host.heartbeat` 默认每 1000 ms（`--heartbeat-ms` 可调），payload
  含 host_id/status/uptime_ms；ring 容量 256。
- 幂等：`params.client_request_id` 必填；host 以该键缓存响应文本（上限
  512，满后清空），重试同键直接返回缓存响应。
- 错误码：`-32700` 解析失败、`-32600` 非法请求、`-32601` 未知方法、
  `-32602` 参数错误、`-32603` 内部错误。

## 4. 状态目录与安全

- 默认 `$MONEXUS_STATE_DIR`，否则 `$HOME/.monexus`；目录 0700。
- `host.json`：临时文件写入后 `rename` 原子发布，权限 0600；字段见
  `packages/contracts/discovery.mbt`。
- `host.lock`：`flock(LOCK_EX)` 单实例；第二个 `serve` 立即报错退出。
- Token：32 字节随机（`@random` + hex），仅通过 0600 文件传递给本机客户端。
- 退出：SIGINT/SIGTERM 使用 `@signal.set_global_cancellation_signals`；
  flock 随进程退出由内核释放。取消路径可能留下旧 `host.json`，下次启动
  覆盖（M1 已知限制）。

## 5. Desktop（MoUI 0.9.1）

- `Model`：`page` + `HostProjection`（link/host_id/version/ws_url/state_dir/
  event_seq/event_count/last_event/last_error）。
- `Msg`：`SelectPage`、`LinkConnecting`、`LinkOnline(HostStatusSnapshot)`、
  `LinkOffline(String)`、`EventArrived(type, seq)`。
- `program()`：`Program::new` + init `Effect::run` 捕获 dispatch；update 只
  做纯状态变更。
- `host_link_loop`：读取 `host.json` → 连接 → `host.status` → 订阅 →
  阻塞等事件；任何失败 dispatch Offline 后 1.5 s 重连。作为窗口任务的
  兄弟任务运行，窗口关闭时由 task group 取消。
- 页面：Home（连接摘要）、Machines、Tasks、Search、Settings（state dir）。
  内容为占位，明确标注 M2–M4 归属。
- 场景注入：`MONEXUS_SCENE_PAGE=home|machines|tasks|search|settings` 与
  `MONEXUS_SCENE_HOST=online|offline` 供 `moui screenshot` 生成确定性快照；
  正常运行不设置这两个变量。

### Linux 原生入口

- MoUI 的 Linux backend 没有 `run_window_with_workers`；使用
  `@async.with_task_group` + `spawn_bg(no_wait=true)` 并行窗口与 host-link
  worker，窗口退出即取消 worker。
- skia 构建需要 Node（prebuild 下载 Skia release）。
- 默认链接 `-lvulkan`；仓库内提供 25 字节 linker script
  `apps/desktop/linux_skia/third_party/vulkan/libvulkan.so`
  （`INPUT ( libvulkan.so.1 )`），并通过
  `cc-link-flags = "-Lapps/desktop/linux_skia/third_party/vulkan"` 使用。
  该相对路径依赖**从仓库根目录**执行 `moon build`；也可设
  `MOUI_SKIA_ENABLE_GPU_VULKAN=0` 规避。
- 无显示服务器时原生窗口创建 panic（MoUI Linux 限制）；headless 用
  `moon test` + `moui screenshot`。

### macOS 原生入口（2026-11-27 补充）

- `apps/desktop/macos_skia/` 与 `linux_skia` 结构相同，使用 MoUI 的
  `backend/macos`、`NativeGpuPlatform::MacOS` 与 `.run_async_pump()`；
  host-link、machine、agent、theme worker 一致。
- 不链接 Vulkan/X11/Wayland；skia 依赖仍由 `moui_skia` 的 prebuild 钩子
  提供链接参数，因此 `macos_skia/moon.pkg` 的 `cc-link-flags` 为空。
- macOS 窗口需要已登录的 GUI session（AppKit/WindowServer）；SSH/纯终端
  环境用 `monexus start --headless`。
- `moon.work`/`moui.project.json` 的 platforms 现为 `["linux", "macos"]`。

## 7. 已知限制 / 遗留

1. **原生窗口**：M1 的 Linux 窗口没有在物理 display 上做交互验证；构建与
   headless 渲染已通过。macOS 入口已在 macOS aarch64 上完成 debug/release
   构建，并在登录 GUI session 中启动窗口、观察到 `link online`；未自动
   驱动窗口控件，CI runner 也没有 GUI session。需要图形环境时按 README
   从登录 session 运行 `monexus`。
2. **WS 客户端**：单请求在途；`request` 期间收到的通知会被丢弃，桌面在
   subscribe 之后才进入 `wait_event`，因此不会丢事件；未来多路请求需要
   请求表/通知分发。
3. **事件持久化**：仅内存 ring（256），重启丢历史、seq 从 1 重新开始。
4. **pid 字段**：pinned 的 async 版本无可移植 `getpid`，`host.status` 与
   `host.json` 中 pid 为 0。
5. **取消清理**：SIGINT/SIGTERM 取消路径可能留下 `host.json`；下次启动
   覆盖，flock 由内核释放。
6. MoUI API 版本锁定 0.9.1；升级需重新验证 `run_async_pump`、
   `WidgetHarness` 与 skia 链接方式。
